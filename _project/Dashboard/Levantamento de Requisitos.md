Projeto:
  - Daya-Agandamentos
ID: LR-0001
Descrição / Objetivo: Levantamento de requisito da pagina Dashboard
---
✔️ O sistema deve exibir a quantidade de cirurgias que está agendada
✔️ O sistema deve exibir a quantidade de cirurgias que está aprovada
✔️ O sistema deve exibir a quantidade de cirurgia que está pendente
✔️ O sistema deve permitir selecionar o médico para obter as informações individualmente, como também, selecionar todos os médicos
✔️ O sistema deve exibir uma lista com as próximas cirurgias agendadas e seu status (Pendente, Aprovado, cancelado)
✔️ O sistema deve exibir uma lista com as últimas cirurgias agendadas
✔️ O sistema deve exibir uma lista com um calendário, onde poderá selecionar uma data e será exibido as cirurgias que estão agendadas para aquela data
✔️ O sistema deve exibir informações da quantidade de cirurgias realizadas e cancelada de cada médico no ano corrente
